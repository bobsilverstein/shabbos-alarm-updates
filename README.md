# Shabbos Alarm updates

The newest Shabbos Alarm app for Android (`ShabbosAlarm.apk`) and its version number (`version.json`).
Installed copies of the app (version 3.3 and later) check `version.json` and update themselves.

To install by hand: download `ShabbosAlarm.apk` on the phone, open it from My Files › Downloads, and tap Install.
